## My Goal

My goal is to understand what I learn, not just complete a course.

I want to practice regularly, improve my problem-solving skills, write better code, and build projects using my knowledge.

I will also revisit my old notes and code, fix mistakes, and make improvements whenever I learn something new.

## How I Study

1. Watch the lecture and read the official notes.
2. Write my own notes in simple English.
3. Type the code myself, run it, and change it to see what happens.
4. Solve practice questions before checking any answers.
5. Come back later to fix mistakes and improve my notes.
